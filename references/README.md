# Материалы для изучения

Галерея относится к следующему этапу. Личные референсы должны храниться отдельно от игровых ассетов и не попадать в игровой экспорт. Папка private исключена из Git.

Для внешнего примера сохраняйте автора, официальную ссылку, цель изучения и реальные условия использования. При неизвестном праве на размещение изображения используйте ссылку и описание.
