# My Game Studio

Личная браузерная мастерская графики для 2.5D RPG: спрайты, слои, покадровая анимация, согласованные палитры, тестовая карта и файловый обмен с **Godot 4.7.2 stable**.

## Открыть студию

На Windows дважды нажмите **«Открыть студию.cmd»**. Нужен установленный Node.js 22.12 или новее. При первом запуске загрузятся бесплатные зависимости. Скрипт проверяет локальный адрес, запускает сервер скрыто и открывает браузер.

Вручную, из папки проекта:

```powershell
npm ci
npm run dev
```

Адрес строго фиксирован: **http://127.0.0.1:5173/**. Если порт занят другим приложением, Vite сообщит ошибку, а не откроет студию на новом адресе с другим хранилищем.

Закрытая веб-копия: [My Game Studio](https://my-game-studio-sunakle.bloomypecan.chatgpt.site). Доступ ограничен владельцем. Репозиторий кода: [sunakle/my-game-studio](https://github.com/sunakle/my-game-studio).

## Первый рабочий цикл

1. Нажмите логотип → создайте проект с понятным названием.
2. «Новый ассет» → 32×32 → «Создать холст».
3. Рисуйте карандашом B. Колесо меняет масштаб; пробел с мышью перемещает вид. Масштаб 1:1 доступен под холстом.
4. Добавьте слой справа. Внизу дублируйте кадр, измените его и нажмите воспроизведение.
5. В разделе «Палитры» сохраните вариант. Назначьте его ассету справа во вкладке «Палитра» или из карточки варианта.
6. Нажмите «Сохранить». Дождитесь «Сохранено на устройстве». Перезапустите браузер и продолжите.
7. На «Карте» проверьте повторение 3×3 / 5×5, масштаб и соседство объектов.
8. В «Экспорте» скачайте PNG, спрайт-лист, JSON, игровой пакет и редактируемый архив.

«Открыть пример» создаёт отдельный демонстрационный проект. Новый собственный проект не заполняется готовыми рисунками. Демонстрационные рисунки созданы специально для этой студии; дерево имеет отдельные слои ствола и кроны, вода — четыре кадра.

## Сохранение

Рисунки хранятся в IndexedDB вашего браузера, отдельно от небольших описаний проекта. Автосохранение срабатывает через секунду после завершённого изменения. Оно не заменяет резервную копию: скачивайте **.mgstudio.zip**.

Хранилища локального адреса и опубликованного сайта различаются. Для переноса скачайте архив и откройте его через логотип → «Открыть архив проекта». Восстановление создаёт новую запись проекта, сохраняя UUID ассетов, слои, кадры, палитры и карту. Существующие проекты не заменяются.

После начала скачивания сайт не утверждает, что файл уже записан на диск. Найдите его в загрузках браузера.

## Проверить в Godot

1. Откройте `godot/demo/project.godot` в **Godot 4.7.2 stable**. Дополнение уже включено.
2. На сайте выберите объект и скачайте «Пакет для Godot».
3. В панели **My Game Studio** справа выберите слот, например «Дерево», и импортируйте `.mgasset.zip`.
4. Запустите сцену клавишей F6 или проект клавишей F5 в редакторе.
5. В игровом окне: WASD / стрелки — движение, L — свет, F5 — обновление пакетов.
6. Измените рисунок в студии, скачайте новый пакет, импортируйте его в тот же слот. В игровом окне нажмите F5.

UUID ассета сохраняется. Обновляются файлы в `generated/<UUID>`, а не ручной код сцены. В тестовой сцене есть трава, тропинка, вода, деревья, камни, простые 3D-руины и управляемый персонаж.

Подробнее: [установка и обмен с Godot](docs/GODOT.md).

## Проверки

```powershell
npm test
npm run build
npm run test:e2e
npm run test:godot
```

Браузерные проверки используют установленный Google Chrome и создают настоящие экспортные пакеты. `test:godot` использует эти пакеты; сначала запустите `test:e2e`. Путь к движку можно указать через `GODOT_BIN`; на этой машине автоматически находится консольный Godot с рабочего стола.

## Границы текущей версии

Работают этап 1 и базовый файловый обмен этапа 2. Нет автоматической синхронизации Godot, отправки рисунков в Git, SVG/AI/ASE-импорта, галереи личных референсов, автоматической перекраски и серверного ИИ. API-ключи не нужны. Платные операции не запускаются.

- Холст: до 1024×1024; слоёв: 32; кадров на ассет: 256; ассетов: 256.
- Пиксельные данные проекта: до 256 МиБ; история изменений: 64 МиБ. История не входит в архив и не переживает перезапуск.
- ZIP на входе: до 64 МиБ; распакованные данные: до 256 МиБ; файлов: до 8192. PNG на входе: до 16 МиБ и 1024×1024.
- Заливка точная по RGBA, прямоугольник контурный, копирование использует внутренний буфер редактора.
- Карта — композиционная проверка в 2D. Автотайлинга и экспорта карты в игровую сцену пока нет.
- Дополнение импортирует один ассет за операцию. Метаданные событий сохраняются, но не управляют боевой системой.
- Настройки камеры и масштаба — стартовая гипотеза. Смешанная графика пока проверена на простом демонстрационном материале.
