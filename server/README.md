# Будущие интеграции

В этой версии сервер не реализован и не требуется. Обычное рисование, сохранение, палитры и экспорт выполняются локально в браузере.

План — отдельный процесс на Node.js/TypeScript для API-помощника и ограниченных интеграций. Контракты и требования описаны в ../docs/INTEGRATIONS.md. Не добавляйте секреты в клиентский код.
