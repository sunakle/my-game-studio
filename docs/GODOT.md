# Godot 4.7.2 stable

## Подготовленный проект

Откройте `godot/demo/project.godot`. Дополнение находится в `addons/my_game_studio` и включено в настройках. В редакторе появляется панель **My Game Studio** справа. Если панель скрыта, проверьте «Проект → Настройки проекта → Плагины».

Для установки в другой проект скопируйте папку `addons/my_game_studio` и включите плагин. Поддерживается зафиксированная версия 4.7.2; другие версии отдельно не проверялись.

## Импорт

1. В студии выберите ассет → «Экспорт» → «Скачать пакет для Godot».
2. В дополнении выберите слот тестовой сцены и сам ZIP. Распаковывать вручную не нужно.
3. Дождитесь сообщения с UUID и папкой. Некорректный пакет возвращает понятную ошибку.
4. В `generated/<UUID>` появятся PNG, JSON, `frames.tres`, `preview_2d.tscn`, `preview_3d.tscn`.
5. В другой игре можно вручную добавить подходящую сцену предпросмотра в собственную сцену. Не пишите ручную логику внутрь generated: эта папка принадлежит импорту.

`SpriteFrames` содержит анимации вида `walk_down`. Скорость библиотеки — один кадр в секунду, а относительная длительность каждого кадра равна реальной длительности в секундах с учётом множителя скорости. Так сохраняются неодинаковые длительности кадров.

2D-сцена использует `AnimatedSprite2D` и пиксельное смещение относительно опоры. 3D-сцена использует `AnimatedSprite3D`, billboard, масштаб `1/pixelsPerUnit` и отдельное преобразование опоры. Для пиксельной техники включены ближайшая фильтрация и отсечение прозрачных пикселей; для других техник — линейная фильтрация и обычная прозрачность.

## Проверить обновление

Сохраните проект в студии, измените один заметный пиксель на видимом слое, скачайте пакет ещё раз. Импортируйте в тот же слот. UUID остаётся прежним, текстуры и ресурсы обновляются.

В запущенной тестовой сцене нажмите **F5** — она перечитает ресурсы с диска. Наличие пакета не означает сетевого соединения между браузером и редактором. Прямого моста нет.

Привязки слотов записываются в `generated/bindings.json`. Ручная логика находится в `scripts/demo.gd`, и импорт её не меняет. Повторная загрузка проверена с изменённым PNG того же UUID.

## Демо и ограничения

WASD / стрелки — движение, L — день/вечер, F5 в игровом окне — перезагрузка ассетов. Встроенные временные материалы процедурные и авторские.

Коллизии демонстрации простые, заданы в ручной сцене для объектов и пола. Метаданные коллизии сохраняются, но универсальное преобразование любых нарисованных форм в 3D-коллизии пока не реализовано. События анимации сохраняются, их запуск боевой логики относится к следующему этапу.

Земля с импортированной анимацией в этой версии показывает её первый кадр. Анимированные Sprite2D / Sprite3D воспроизводят все кадры; анимированный материал воды на плоскости — дальнейшая доработка.

Пакет проверяется полностью до замены сгенерированных файлов. При ошибке записи на диск может потребоваться повторить импорт; общей атомарной транзакции для всех файлов Godot пока нет. Ручные ресурсы не заменяются. Количество ассетов в одном пакете v1 ограничено одним.

На рабочей машине был выполнен запуск с OpenGL-рендерингом и сохранён кадр сцены. Ограниченная среда проверки выводит предупреждения о системном хранилище сертификатов и кэше шейдеров; это не ошибки компиляции проекта. Интернет для демонстрации не нужен.
