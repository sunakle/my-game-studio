# Форматы v1

## Редактируемый проект: .mgstudio.zip

`project.json` содержит `schemaVersion: 1`, UUID и имя проекта, даты, описания ассетов, слои, кадры, анимации, палитры, задачи, карту, параметры стиля и рабочего пространства. Пиксели каждого кадра и слоя хранятся в PNG по адресу `cels/<assetId>/<frameId>/<layerId>.png`.

В оперативной памяти cel — `Uint8ClampedArray` RGBA. В IndexedDB это бинарные данные, не base64. В JSON архива cel заменяется относительным путём к PNG. Прозрачность не смешивается с шахматной подложкой, направляющими, сеткой или опорой.

Данные анимации: UUID, имя, `speed`, `loop`, `sequences` с ключами `down`, `left`, `right`, `up`. Последовательности содержат UUID кадров. Кадр хранит `durationMs`, свои cels, `pivotOffset` и события `{id, name, offsetMs}`.

Вложенные Illustrator-оригиналы пока не поддерживаются. Их отдельное бинарное хранилище и ссылки будут добавлены вместе с реальным импортом на следующем этапе. Импорт PNG в этой версии сохраняет растр в редактируемом слое.

Неизвестная версия отклоняется. Совместимый v1 без новых настроек вида получает пустые настройки вида по умолчанию. Новые структурные версии потребуют явной миграции; текущие исходные записи не удаляются.

## Игровой пакет: .mgasset.zip

Корень: `manifest.json` с `schemaVersion: 1`, `generator` и массивом `assets`. Текущий экспорт создаёт пакет одного выбранного ассета.

Изображения:

- `assets/<UUID>/sheet.png` — атлас;
- `assets/<UUID>/frames/<frameUUID>.png` — сведённые отдельные кадры.

Для каждого ассета передаются:

- UUID, название, тип, техника, происхождение;
- ширина, высота, `pixelsPerUnit`, перечень файлов;
- версия палитры и её идентификатор;
- опора, коллизия и события;
- список кадров с `rect`, `durationMs`, итоговой опорой и событиями;
- именованные анимации, четыре направления, последовательности, скорость и цикл;
- размеры атласа, поле 2 px и extrusion 1 px.

Координаты исходного изображения — пиксели, начало сверху слева. `rect = {x,y,w,h}` исключает поля. Кадры не обрезаются по содержимому. Внешний пиксель поля дублирует край кадра, включая углы; второй пиксель остаётся прозрачным.

Для независимого скачивания метаданных путь к атласу меняется на `<имя>-sheet.png`, соответствующий отдельному скачиванию спрайт-листа. Каноническую структуру для дополнения содержит именно полный игровой пакет.

PNG экспорта отдельного кадра содержит только видимые слои с учётом их непрозрачности. Скрытые слои сохраняются в редактируемом архиве.

## Палитры и происхождение

Сохранённый вариант палитры имеет UUID и номер версии. Новая сохранённая версия получает новую запись; предыдущие записи остаются доступными для назначенных ассетов. Изменение варианта в предпросмотре не меняет рисунки и назначенные версии.

`origin`: `own`, `imported`, `demo`. Это заявленное происхождение, а не автоматическое подтверждение лицензии.

## Лимиты и проверка

Лимиты перечислены в README. Архивы с выходом за каталог, неизвестной структурой, отсутствующими кадрами или слоями и несовпадением размеров не открываются. На веб-стороне проверяется и совокупный объём декодируемых слоёв. Дополнение проверяет центральный каталог ZIP до распаковки, читает только JSON и PNG и не исполняет содержимое пакета.
