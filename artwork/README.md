# Исходники графики

Ваши текущие рисунки находятся в IndexedDB и редактируемых .mgstudio.zip-архивах. Автоматической отправки в репозиторий нет.

Папка private исключена из Git. Illustrator/PSD-оригиналы и чужие референсы не отправляются. Для выбранных версий ассетов позже нужно согласовать политику хранения и при необходимости Git LFS.

Демонстрационные материалы этой версии создаются собственными алгоритмами из src/core/demo.ts и godot/demo/scripts/demo_art.gd. Чужие игровые ассеты не включены.
